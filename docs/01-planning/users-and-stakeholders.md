# 사용자 및 이해관계자 분석

## 1. 사용자 선정

이 프로젝트의 주요 사용자는 유통 관계자로 정의한다.

유통 관계자는 여러 품목의 현재 시세와 최근 흐름을 빠르게 비교하고, 수급 위험이 높은 품목을 먼저 파악해야 한다. 따라서 첫 화면은 품목별 현재 시세와 간단한 가격 흐름이 담긴 카드형 전체 대시보드로 구성한다.

## 2. 주요 사용자

| 항목 | 내용 |
|---|---|
| 사용자 유형 | 주요 사용자 |
| 사용자 그룹 | 유통 관계자 |
| 사용자 목표 | 전남 특산 농수산물의 현재 시세, 최근 가격 흐름, 위험 등급을 빠르게 확인하고 거래 및 수급 판단에 참고한다. |
| 현재 어려움 | 여러 품목의 가격을 한눈에 비교하기 어렵고, 가격 변동이 위험 신호인지 단순 변동인지 판단하기 어렵다. |
| 주요 행동 | 전체 대시보드 확인, 품목 선택, 기간별 가격 추이 조회, 위험 점수 확인, AI 질문, 답변 피드백 제출 |
| 필요한 정보 | 품목명, 현재 가격, 단위, 최근 변화율, 간단한 추세, 위험 등급, 갱신 시각, 데이터 출처, 계산 근거 |
| 사용 환경 | 업무 중 PC 중심 사용. 필요 시 태블릿 또는 모바일 브라우저에서 현황 확인 |
| 신뢰 조건 | KAMIS 출처 표시, 데이터 기간 표시, 갱신 시각 표시, 위험 점수 계산 근거 표시, AI 답변 근거 표시 |

## 3. 보조 사용자

| 사용자 | 목표 | 필요한 정보 | 권한 고려 |
|---|---|---|---|
| 생산자 | 본인 품목의 시세 흐름과 위험도를 참고한다. | 품목별 현재 가격, 추이, 위험 등급 | 공개 가격/위험 정보 조회 |
| 지역 행정 담당자 | 지역 특산품 가격 변동과 수급 위험을 모니터링한다. | 고위험 품목, 수집 상태, 데이터 품질 | 공개 정보 및 시스템 상태 일부 조회 |
| 시장 분석 담당자 | 가격 흐름과 위험 분석 결과를 보고서에 활용한다. | 기간별 지표, 위험 근거, 과거 분석 문서 | 공개 정보 및 AI 보고서 조회 |
| 교육 과정 수강생 | PRD 기반 개발 흐름과 Supabase/Pinecone/RAG 구조를 학습한다. | 문서, 구현물, 테스트 결과 | 개발 저장소 접근 |

## 4. 사용자별 핵심 요구

| 사용자 | 핵심 요구 |
|---|---|
| 유통 관계자 | 첫 화면에서 여러 품목의 현재 시세와 간단한 흐름을 비교할 수 있어야 한다. |
| 생산자 | 특정 품목의 가격 추이와 위험 등급을 쉽게 확인할 수 있어야 한다. |
| 지역 행정 담당자 | 고위험 품목과 데이터 수집 실패 상태를 구분할 수 있어야 한다. |
| 시장 분석 담당자 | 분석 결과의 수치 근거와 사용 기간을 확인할 수 있어야 한다. |
| 교육 과정 수강생 | PRD 요구사항과 실제 구현/테스트의 연결 관계를 확인할 수 있어야 한다. |

## 6. 신뢰 조건

사용자가 결과를 신뢰하려면 다음 정보가 함께 제공되어야 한다.

1. 가격 데이터 출처
2. 데이터 수집 시각
3. 분석 대상 기간
4. Mock 데이터 여부
5. 결측치 또는 데이터 부족 여부
6. 위험 점수 계산 근거
7. AI 답변에 사용된 Supabase 수치와 Pinecone 근거 문서
8. AI 답변의 데이터 한계
